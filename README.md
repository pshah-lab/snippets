# PshahLab snippets

Small, runnable code from the PshahLab "Tech in 60" Shorts. One folder per topic, named after the episode title, holding the code file shown in the video (named `epNNN-<topic>.<ext>`). The video's description says which folder and file to open.

| Episode | File | What it shows | Run |
| --- | --- | --- | --- |
| ep-016 | [rags-first-step-in-ten-lines-of-python/ep016-retrieve.py](rags-first-step-in-ten-lines-of-python/ep016-retrieve.py) | The retrieval step of RAG as a toy: pick the document that shares the most words with the question | `python3 rags-first-step-in-ten-lines-of-python/ep016-retrieve.py` |
| ep-017 | [the-rag-metadata-trick/ep017-metadata-filter.py](the-rag-metadata-trick/ep017-metadata-filter.py) | Filter chunks by metadata (company, quarter) before ranking, so the right chunk wins | `python3 the-rag-metadata-trick/ep017-metadata-filter.py` |
